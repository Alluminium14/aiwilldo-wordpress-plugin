# Tabler Icons — local design reference

Official source archive downloaded from:

https://github.com/tabler/tabler-icons/archive/refs/heads/main.zip

Official icon browser:

https://tabler.io/icons

This folder contains the full SVG set from the official repository's `icons/`
directory, including `outline/` and `filled/` variants. It is a local reference
for developers and AI agents only; no icons from this folder are automatically
loaded by the public landing.

When an icon is chosen, copy only the required SVG markup into the semantic
component. Keep the existing single outline icon language unless a deliberate
design change is requested. Do not enqueue the whole library for visitors.
